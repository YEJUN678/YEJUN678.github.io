소개

Pixwave란

앱, 웹, 게임에 넣을 사운드를 찾는大多数人에게는 같은 문제가 있습니다. 검색하면 양질의 파일은 대부분 유료이고, 무료 파일은 라이선스가 애매하거나 용도에 맞지 않습니다.

Pixwave는 파일을 모아두는 대신 필요한 소리를 직접 만들어 제공합니다.59개 팩 485개 사운드가 22개 카테고리로 정리되어 있습니다.

어떻게 동작하나요

  1. 01

    파라미터로 사운드를 정의합니다

    매 샘플을 직접 녹음하지 않습니다. 주파수, 파형, 감쇠, 노이즈 같은 값으로 사운드를 서술해 두기 때문에, 언제든 같은 소음을 다시 만들 수 있습니다.

  2. 02

    미리듣기는 실제 샘플로 재생합니다

    재생 버튼을 누르면 그 자리에서 오디오 버퍼를 만들어 그대로 재생합니다. 오디오 파일을 스트리밍하지 않으므로 로딩이 없어요.

  3. 03

    다운로드는 같은 샘플을 WAV로 저장합니다

    받은 파일은 44.1kHz / 16-bit 모노 PCM입니다. 미리듣은 소리와 받은 파일은 픽셀 단위로 동일합니다.

어디에 쓰나요

  • 안드로이드 앱

    res/raw 에 넣고 SoundPool 또는 MediaPlayer 로 재생. 포맷 호환이 끝내 맞습니다.

  • 웹 / PWA

    Web Audio API 로 재생하거나, 받은 WAV 를 정적 파일로 배포하세요.

  • iOS

    Bundle 에 복사해 AVAudioPlayer 로 재생. 샘플레이트 44.1kHz 표준 지원.

  • 게임

    짧은 효과음 위주라 지연 없이 재생됩니다. 배경음은 루프용 팩을 추천.
